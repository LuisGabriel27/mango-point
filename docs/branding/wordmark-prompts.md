# MangoPoint logo with name

Generated and refined using the built-in image generation tool.

Final asset: [mangopoint-wordmark-v3.png](../../frontend/public/brand/mangopoint-wordmark-v3.png).

The final image uses a white background; it is not a transparent PNG.

## Design prompt

```text
Use case: logo-brand
Asset type: complete professional MangoPoint logo with brand name, suitable for the application's website header, login page, reports, and presentations.
Input image 1: reference symbol to retain, a golden mango with a geographic location hole and a green leaf.
Primary request: create a polished horizontal logo combining the reference mango symbol on the left and the exact word "MangoPoint" on the right. The name MUST be part of the delivered image.
Text (verbatim): "MangoPoint". Spell M a n g o P o i n t, with capital M and P, no space between the words. No other text.
Typography: distinctive premium geometric sans-serif, bold weight, smooth slightly rounded details, meticulous kerning, confident and professional agricultural technology identity. Single baseline, very readable at small sizes. Use solid deep forest green #1B4332 for the entire wordmark.
Symbol: preserve the reference mango/map-pin concept, warm gold fruit, simple green leaf, clean circular negative-space hole, but clean up any stray pixels. Flat clean shapes and sharp antialiased contours.
Composition: a compact horizontal brand lockup on a wide 3:1 canvas, with the symbol to the left and the wordmark to the right; symbol only about 1.35 times the capital letter height. Center the whole lockup vertically. Keep the name visually prominent. Use a restrained gap between icon and name and narrow equal outer margins. Use available canvas width; no oversized symbol, no tiny name.
Background: genuinely transparent alpha PNG, also transparent inside the symbol hole and letter counters; do not draw checkerboard squares.
Constraints: one logo only. No tagline, no framing, no board, no mockup, no extra decoration, no shadow, no glow, no bevel, no metallic texture, no watermark. Logo graphics must be clean and flat.
```

## Background refinement

The transparency attempt retained a painted checkerboard, so the final refinement produced the white background used by the login panel.

```text
Use case: precise-object-edit
Input image is the edit target.
Replace all gray checkerboard areas with perfectly uniform solid pure white #FFFFFF, including inside the mango hole and all letter counters. Use an opaque white background, no transparency. Preserve the MangoPoint logo design exactly: the existing mango icon, green leaf, exact word "MangoPoint", typography, colors, positioning, spacing, and 3:1 horizontal aspect ratio. No checkerboard, no paper texture, no shadows, no extra text. Deliver a clean finished professional logo on plain white.
```
